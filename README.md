# GreenPoints: A School Waste-Segregation Reward Tracker
GreenPoints allows users to log and categorize waste and automatically assigns points. The students can then use their points to redeem prizes. There is also a live leaderboard which ranks classes or zones and a monthly report which indicates the amount of kilograms of waste being diverted from the landfill.
